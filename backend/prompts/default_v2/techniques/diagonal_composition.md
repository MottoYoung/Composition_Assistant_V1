# 任务请求
用户已经上传一张图片。请应用 Diagonal Composition（对角线构图）。

支持该技术的视觉证据：
- 画面中已经存在真实对角线动势：道路、小径、围栏、楼梯、建筑边缘、桥、海岸线、树干、肢体、阴影或物体布局形成明显斜向轴线。
- 主体或场景元素本身以角度跨越画面，或可以通过重新取景形成这种效果。
- 透视退线以斜向穿过画面，而不是直直指向画面中心。

排除条件：
- 场景中不存在真实对角线结构。不要通过倾斜相机伪造对角线动势，那会制造不稳定和眩晕感，而不是构图张力。
- 对角线动势太弱或太小，无法在画面中清晰读出。
- 最终效果基本只是普通三分构图，没有明确对角线特征。

动作偏好：
- 优先使用 `Shift` 和 `Orbit`，让现有对角线元素跨越画面。
- 当更低或更高机位能强化对角线观感时，使用 `LowerCamera` 或 `RaiseCamera`。
- `Level CCW` 或 `Level CW` 只可用于轻微水平校正，不可用于制造对角线。
- 对角线应明显并形成清晰视觉动势，而不是轻微倾斜。
