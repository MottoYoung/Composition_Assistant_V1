# 任务请求
用户已经上传一张图片。请应用 Center Composition / Symmetry（中心构图 / 对称构图）。

支持该技术的视觉证据：
- 存在单一主导主体，且主体本身具有对称性或中心轴，例如人脸、门洞、走廊、隧道、建筑立面、拱门、反射等；居中后会显得更有意图感。
- 场景具备左右或上下平衡关系，但当前取景明显偏离中心。
- 主体具有强中心轴，例如塔、树、纪念碑；居中可以强调稳定感、庄重感或权威感。

排除条件：
- 当前画面已经接近居中，再居中只能带来微小改善。
- 主体缺少对称性或中心主导性，强行居中会显得任意。
- 居中效果必须依赖移动真实物体。

动作偏好：
- 优先使用 `Shift` 和 `Level` 修正对齐，再考虑机位变化。
- 只有当居中结果确实需要新视点才能成立时，才使用 `Step` 或 `Orbit`。
- 最终居中画面应明显比原图更有意图感，而不是仅仅稍微不那么偏。
