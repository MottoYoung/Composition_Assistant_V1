# 任务请求
用户已经上传一张图片。请应用 Foreground Framing（前景 / 框架构图）。

支持该技术的视觉证据：
- 画面边缘或场景前方已经可见真实前景元素：拱门、门框、窗框、垂下的树枝、岩石、篱笆柱、立柱、窗帘，或任何能部分围住主体的物体。
- 现有前景元素距离相机足够近，可以通过重新取景让它成为主体周围或边缘的框架。
- 局部框架也有效，例如单侧、上边缘或下边缘；不要求完整包围主体。

排除条件：
- 场景中没有真实前景或框架候选。绝不伪造树叶、窗户、虚化光斑、杆子或框架元素。
- 前景元素太远、太小或太弱，无法读作框架。
- 前景 / 框架效果含糊，或只比原图略强一点。

动作偏好：
- 优先使用 `Step Forward` 或 `LowerCamera` / `RaiseCamera`，把前景元素带入可形成框架的位置。
- 使用 `Shift` 将前景框架与主体对齐。
- 最终结果应呈现清晰层次，并有明显的框架元素围绕或贴近主体。
