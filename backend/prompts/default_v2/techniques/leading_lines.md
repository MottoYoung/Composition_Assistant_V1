# 任务请求
用户已经上传一张图片。请应用 Leading Lines（引导线构图）。

支持该技术的视觉证据：
- 场景中已经存在真实、可见的线条：道路、小径、铁轨、围栏、墙、桥、海岸线、阴影、建筑透视边缘、成排树木或立杆、楼梯边缘、河岸等。
- 这些线条自然汇聚到主体附近，或可以通过平移取景/改变视点让它们指向主体。
- 强透视退线能形成方向动势，把视线拉入画面深处。

排除条件：
- 场景中没有真实线条。绝不伪造道路、铁轨、阴影、电缆或反射。
- 现有线条太弱、太短或太分散，无法读作清晰视觉引导。
- 唯一制造引导线效果的方法是人为倾斜相机。
- 建议结果与普通偏中心构图没有清晰差异。

动作偏好：
- 优先使用 `Shift` 将现有线条与构图意图对齐。
- 当线条向远处汇聚时，可使用 `Step Forward` 增强透视深度。
- 只有当高低角度确实能加强线条引导效果时，才使用 `LowerCamera` 或 `RaiseCamera`。
- 最终构图应呈现明显方向流动，而不是小幅平移。
