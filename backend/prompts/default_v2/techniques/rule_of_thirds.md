# 任务请求
用户已经上传一张图片。请应用 Rule of Thirds（三分构图）。

支持该技术的视觉证据：
- 存在清晰主主体（人物、物体、建筑、树、动物等），当前接近中心或位于不理想的一侧，并且可通过取景让它落在三分线或三分交点上，同时形成有意义的留白。
- 存在地平线或强水平边界，当前过于居中，放到上三分或下三分会更有动势。
- 存在强垂直元素（杆、树干、边缘等），可以锚定三分线。

排除条件：
- 主体已经很好地落在三分线或三分交点上。
- 让主体落到三分位置只需要极小裁切或微移，视觉差异不明显。
- 该技术需要移动真实物体，而不是重新取景。

动作偏好：
- 优先使用 `Shift`。只有当三分放置确实需要新机位时，才使用 `Step` 或 `Orbit`。
- 目标是形成视觉上更清楚的三分构图，而不是最小幅度微调。
